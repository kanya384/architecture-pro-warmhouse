### Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи могут управлять отоплением в доме через веб интерфейс.
- Система позволяет обновлять температуру датчика по его id

**Мониторинг температуры:**

- Пользователи могут просматривать температуру в доме через веб интерфейс.
- Система поддерживает просмотр температуры по локации.

**Управление датчиками :**

- Сотрудники компании могут получать список всех датчиков через веб интерфейс.
- Сотрудники компании могут просматиравть информацию о конкретном датчике через веб интерфейс.
- Сотрудники компании могут создавать новые датчики через веб интерфейс
- Сотрудники компании могут обновлять датчики через веб интерфейс
- Сотрудники компании могут удалять датчики через веб интерфейс
- Система позволяет получать список всех датчиков
- Система позволяет получать конкретный датчик по его id
- Система позволяет создавать новые датчики
- Система позволяет обновлять датчик по его id
- Система позволяет удалять датчики

### Анализ архитектуры монолитного приложения

Перечислите здесь основные особенности текущего приложения: какой язык программирования используется, какая база данных, как организовано взаимодействие между компонентами и так далее.

- Язык программирования: GO
- База данных: PosgreSQL
- Архитектура: Все компоненты системы (обработка запросов, бизнес-логика, работа с данными) находится в рамках одного приложения.
- Взаимодействие: Синхронное, запросы обрабатываются последовательно.
- Масштабируемость: Ограничена, так как монолит сложно масштабировать по частям.
- Развертывание: Требует остановки всего приложения.

### Диаграмма контекста

```puml
@startuml
title Диаграмма контекста «Тёплый дом»

top to bottom direction

!includeurl https://raw.githubusercontent.com/RicardoNiepel/C4-PlantUML/master/C4_Component.puml

Person(user, "Пользователь", "Пользователь системы умный дом")
Person(admin, "Сотрудник", "Сотрудник компании")
System(backend, "Система «Тёплый дом»", "Просмотр темературы и управление датчиками отопления")

System_Ext(sensor, "Датчики управления отоплением", "API для интеграции с датчиками")
Rel(user, backend, "Пользуется системой")
Rel(admin,backend,"Управляет системой")
Rel(backend,sensor,"Устанавливаем температуру")
Rel(sensor,backend,"Передаем текущую температру")

@enduml
``` 
